# TATSULOK

TATSULOK is an interactive puzzle-game lobby about power, mystery, corruption, development, and democracy.

## Ang Mundo ng TATSULOK

Tatlong panig ng lipunan ang nagtatagpo:

- PANGINOON
- MALAKAS
- MABUTI

Bawat karakter ay may sariling kapangyarihan, papel, at paninindigan.

Ang layunin ay unawain ang misteryo sa likod ng kapangyarihan habang hinaharap ang iba't ibang hamon tulad ng baha, lindol, korapsyon, at pang-aalipin.

## Features

- Interactive character selection
- 11 playable characters
- Faction filtering
- Character dossier
- Player name input
- READY state
- Start Mission flow
- Mission screen
- Local progress/status interface
- Responsive desktop, tablet, at mobile layout
