# TATSULOK

Interactive first-person 3D puzzle game about power, mystery, corruption, development, and democracy.

Playable prototype: lobby, characters, dossiers, factions, missions, and a true first-person 3D district.

## Play locally

```bash
npm install
npm run dev
```

### Controls

- Desktop: click to look, WASD move, Shift run, E interact
- Mobile / iPad: left joystick, drag to look, RUN / INTERACT
- BACK returns to the mission list

## Mission 01

Flooded street → survivor → clue → blocked road → side street → supplies → evacuation center → choice.

## Deploy

- Build: `npm run build`
- Publish: `dist`

Status: playable first-person prototype.
